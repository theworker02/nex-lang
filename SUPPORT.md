# Support

Where to get help with **Nexus** ([theworker02/nex-lang](https://github.com/theworker02/nex-lang)).

## Ask a question

1. Check the docs: [`vscode-nexus/docs/README.md`](vscode-nexus/docs/README.md) and [Getting started](vscode-nexus/docs/getting-started.md).
2. Browse existing [GitHub Issues](https://github.com/theworker02/nex-lang/issues) and Discussions (if enabled).
3. Open a new issue with the **question** or **discussion** framing — include OS, Node version, and the exact command you ran.

## Report a bug

Use [GitHub Issues](https://github.com/theworker02/nex-lang/issues/new) with:

- Expected vs actual behavior
- Minimal reproduction (`.nex` snippet or steps)
- `node out/cli.js version` (from `vscode-nexus` after `npm run compile`)
- OS and Node.js version

## Security

Do **not** file public issues for vulnerabilities. See [SECURITY.md](SECURITY.md).

## Commercial / SLA support

There is **no paid support SLA**. This is an open-source project maintained by **theworker02 / nex-lang project maintainers** on a best-effort basis.
